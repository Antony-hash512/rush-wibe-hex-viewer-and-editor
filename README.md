# Short description:
This is a plain viewer for files in hexadecimal format.
It was created by vibe-coding on the Rust language using GTK for the graphical interface.
Editing functionality is planned for one of the upcoming versions in the main branch.
This branch 'viewer' is fully completed.
In this branch, the utility is designed only for viewing.

# Main purpose:
This viewer (and in the future editor) is a kind of template as a basis for studying the Rust language and the GTK library, as well as for creating more specialized and functional programs on its basis.

# Краткое описание:
Простой просмотрщик файлов в шестнадцатеричном формате.

Сделан при помощи вайб-кодинга на языке Rust с использованием GTK для графического интерфейса.

Функционал по редактированию файлов запланирован в ближайших версиях в основной ветке git.

Данная ветка viewer является полностью завершённой.

В ней данная утилита предназначена только для просмотра файлов.

# Основное задуманное предназначение: 

Данный просмотрщик (и в будущем редактор) является по сути макетом как для изучения языка программирования Rust и библиотеки GTK, так и для дальнейшего создания на его основе более специализированных и функциональных программ.
